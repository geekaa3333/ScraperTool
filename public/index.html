Amazon marketplaces

A file uploaded under a marketplace belongs to that marketplace. Its ASINs are scraped there directly — no cross-region availability checks are performed.

Auto detection — check these marketplaces

Each ASIN is checked against every selected marketplace. A check is a real page load, so the work grows quickly — the planned total is shown before you start.

Mixed-marketplace batches do not use a shared delivery destination. Each marketplace is handled with its own location, and anything not configured for that marketplace is left as Amazon's own default rather than being assumed.

Or paste ASINs or Amazon URLs directly
